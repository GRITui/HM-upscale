# HM-upscale

A personal, non-commercial Unity 6 remake of a 2006 PSP farming game, rebuilt as a high-fidelity 3D game that keeps the original style, world, characters and story.

Tracking: see the epic (issue #1) and phase issues #2-#13.

## No game data in this repo

This repository contains code, tools, documentation and original placeholder art only. It never contains the game ISO/CHD, the decrypted executable, extracted or converted game assets, or upscaled textures. Those live in `assets/` (git-ignored) on the developer's machine. A pre-commit hook (`tools/hooks/pre-commit`, installed by `tools/install-hooks.sh`) rejects game-data extensions, anything under `assets/`, and files over 5 MB.

Converter tests use synthetic fixtures generated by the tests themselves.

## Layout

- `tools/` - ingestion and conversion tooling (`hmconv`), hooks
- `docs/` - setup, inventory, format specs, rule specs, ADRs
- `unity/` - Unity 6 project
- `assets/` - local only, git-ignored
